Entry for [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) — one word my ex would use to describe me:

> **"Almost"**

## Why this word

Almost the one. Almost enough. Almost there. It is the word for the
boyfriend who was close enough to hurt and never close enough to
keep — the practice run before the real thing, the lesson someone
else got to benefit from. It stings because it is true, and it is
funny for exactly the same reason: everybody has been somebody's
almost, or had one. One word, and she would not need a second.
